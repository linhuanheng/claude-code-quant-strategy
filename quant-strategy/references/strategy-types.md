# 策略类型详解

## 策略选型决策树

```
用户策略想法
├── alpha 来源明确（特定因子/信号）
│   ├── 横截面（选股）──────────────→ 多因子选股策略
│   └── 时间序列（择时）───────────→ 单资产/指数择时策略
├── alpha 来源是统计关系
│   ├── 两个品种（配对）───────────→ 协整配对交易
│   ├── 多个品种（篮子）───────────→ 统计套利
│   └── 跨品种/跨市场───────────────→ 跨市场套利
├── alpha 来源是事件/信息
│   ├── 财报/预告/公告─────────────→ 事件驱动策略
│   └── 新闻/舆情───────────────────→ 另类数据策略
├── alpha 来源由模型学习
│   └── 多特征非线性关系───────────→ ML 驱动策略
└── 无明确 alpha 来源，只有方向判断 → 趋势跟踪/CTA
```

## 策略类型详述

### 1. 横截面多因子选股

**核心逻辑**：在某一个时间截面上，通过因子值对股票排序，做多高因子值股票、做空低因子值股票（或仅做多前 N%）。

**信号形式**：截面排名分位数 → 目标权重

**关键参数**：
- 调仓频率（月度/周度）
- 分组数量（通常等权或市值加权）
- 持仓数量（top N 或 top K%）
- 行业中性化是否启用

**所需数据**：
- 行情：`daily`, `adj_factor`, `daily_basic`
- 财务：`income`, `balancesheet`, `cashflow`, `fina_indicator`
- 因子：`stk_factor_pro`（可直接用或自建）
- 成分：`index_member`（指定股票池）

**常见变体**：
- 单因子选股：仅用 1 个因子排序
- 复合因子：多因子等权/ICIR 加权合成
- 行业中性：各行业内独立排序后组合
- 指数增强：跟踪指数 + 主动偏离（通常做多全组合，无做空）

### 2. 时序择时策略

**核心逻辑**：对单一资产（指数/个股）预判未来方向的涨跌，决定仓位比例。

**信号形式**：看多/看空/空仓，仓位权重 0-100%

**关键参数**：
- 信号滞后（T 日信号 → T+N 日执行）
- 仓位离散度（满仓/半仓/空仓 vs 连续仓位）
- 阈值参数

**所需数据**：
- 行情：`daily`, `index_daily`
- 资金流：`moneyflow`, `moneyflow_hsgt`
- 情绪：`margin` (两融), `limit_list` (涨跌停)
- 技术指标：基于价格量计算

**常见变体**：
- 均线交叉（双均线/三均线）
- 通道突破（布林带/唐奇安通道/ATR 通道）
- 动量择时（时间序列动量）
- 波动率择时（低波动加仓、高波动减仓）
- 宏观指标择时（PMI、社融、利率）

### 3. 统计套利

**核心逻辑**：识别资产间的长期均衡关系（协整），当短期偏离时做多低估、做空高估，等待回归。

**信号形式**：价差 z-score → 多空配对

**关键参数**：
- 协整检验窗口（用于估计协整关系的样本长度）
- 开仓阈值（如 z > 2 或 z < -2）
- 平仓阈值（如 z 回归到 0 附近）
- 止损阈值
- 配对选择标准

**所需数据**：
- 行情：`daily` + `adj_factor`
- 多品种同时获取

**关键注意**：
- 协整关系估计窗口必须早于交易窗口
- 协整关系可能随时间变化，需定期重新估计
- 配对筛选不可使用全样本协整检验结果

### 4. 事件驱动策略

**核心逻辑**：特定公司事件（业绩预告、分红、回购、定增、ST、举牌等）发生后，股价存在系统性可预测的反应模式，利用该规律交易。

**信号形式**：事件触发 → 买入/卖出 → 持有 N 天后平仓

**关键参数**：
- 事件窗口（事件前后各多少天）
- 持有期
- 过滤条件（市值、流动性等）

**所需数据**：
- 事件数据：`forecast`（业绩预告）, `dividend`（分红）, `repurchase`（回购）, `pledge_stat`（股权质押）, `share_float`（解禁）
- 行情数据：`daily`, `stk_factor_pro`
- 公告：`disclosure_date`（披露日期）

**关键注意**：
- 事件公告日期 ≠ 实际发生日期，信号以公告日为基准
- 需确认信息在公告日前不被泄露（避免前视偏差）
- 样本量可能较小，统计推断需更保守

### 5. CTA / 趋势跟踪策略

**核心逻辑**：价格趋势具有持续性（动量效应），顺势而为。趋势确立后入场，趋势反转信号出现时离场。

**信号形式**：多头/空头/平仓信号

**关键参数**：
- 趋势识别窗口
- 反转判定窗口
- 波动率过滤

**常见实现**：
- 双均线系统
- 唐奇安通道突破
- ATR 动态止损跟踪
- 海龟交易法则

**所需数据**：
- 行情：`daily` 或 `index_daily`

### 6. ML 驱动策略

**核心逻辑**：使用机器学习模型从多维特征中学习预测未来收益的非线性关系。

**信号形式**：模型预测值 → 截面排名 → 分组

**关键约束（极其重要）**：
- **必须按时序切分训练/验证/测试集**，不能随机 shuffle
- 训练集 [T_start, T_split]，验证集 [T_split+1, T_val_end]，测试集 [T_val_end+1, T_end]
- 或使用 walk-forward：每年用前 N 年数据训练，预测下一年
- Purge-embargo：训练集和测试集之间必须有间隔，避免标签泄露
- 特征计算同样必须 PIT：训练集上的标准化参数用于验证/测试集

**常用模型**：
- 线性：Ridge/Lasso/ElasticNet （可解释性好）
- 树模型：XGBoost/LightGBM（非线性、特征重要性）
- 神经网络：简单 MLP（适用于大数据量）

**所需数据**：与多因子选股相同，但需要更多维度的数据作为特征。

## 关键设计确认清单

在开始编写策略代码前，必须与用户确认：

- [ ] 策略类型是什么？
- [ ] alpha 来源（凭什么赚钱）？
- [ ] 持仓周期和调仓频率？
- [ ] 股票池范围？
- [ ] 基准指数？
- [ ] 是否做空？
- [ ] 单边还是多空？
- [ ] 资金管理方式（等权/市值加权/等波动率）？
- [ ] 是否有行业中性/市值中性要求？
